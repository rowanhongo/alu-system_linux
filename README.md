# alu-system_linux

Projects from the ALU Software Engineering system programming track (Linux, C, Python internals).

## Projects

| Directory | Description |
|-----------|-------------|
| [0x08_CPython](./0x08_CPython) | C extensions and tools for Python internals: lists, bytes and float objects, and the big-O of list operations |
| [nm_objdump](./nm_objdump) | Re-implementations of the `nm` and `objdump` binary inspection tools (`hnm`, `hobjdump`) in C, for 32 and 64-bit ELF files |

## Requirements

- Ubuntu 20.04 LTS (or similar Linux)
- `gcc`, `make`
- Python 3.4+ with the development headers (for `0x08_CPython`)

## Building

Each project has its own README with build and usage instructions, for example:

    cd nm_objdump
    make
